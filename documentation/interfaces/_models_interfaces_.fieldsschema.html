Optional semantic_type

semantic_type: Array<string>
  • Defined in models/interfaces.tsx:198

Semantic types are "human understandable types". Those special tags are used to give some meaning to the field/data. A field has to contain at least 2 semantic types (key-value pair). For example, a field can be of semantic type: customer, email. This means that the data will be an email, part of the "category/group" email. This makes more sense if we take an address as an example: for an address we will have a zip, city, street, ... part of the "group" address...
